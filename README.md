# 🔮 AURA AI Mobile Companion App

> A next-generation multimodal voice, vision, and collaborative mobile AI companion app with an audio-reactive glowing aura orb.

---

## 🌟 Key Features

1. **Audio-Reactive Glowing Aura Orb**: Real-time fluid particle canvas orb that pulses dynamically with speech and voice synthesis.
2. **Real-Time Voice Assistant**: Full speech-to-text (microphone input) and natural SpeechSynthesis voice playback.
3. **AI Personality Modes**:
   - ⚡ **AURA Prime**: Omniscient, warm multimodal companion.
   - 💻 **Cyber Nexus**: Futuristic tech & code specialist.
   - 🧘 **Zen Muse**: Mindfulness, clarity, and deep thinking.
   - 🌟 **Creative Spark**: Storytelling, art, and brainstorming.
4. **Multimodal Vision Scanner**: Upload and scan camera photos with instant neural breakdown.
5. **Friend Sync & Shared Session Room**: Generate private 6-digit room codes to collaborate and chat simultaneously with your friend across multiple phones.
6. **Mobile-First App PWA**: Designed for mobile touch manipulation, dynamic status bars, and installable on Android and iOS via *"Add to Home Screen"*.

---

## 📱 How to Run & Download on Your Phone

### Option A: Open on Your Local Mobile Device (Same Wi-Fi)
1. Ensure your phone and computer are on the same Wi-Fi network.
2. On your phone's browser (Safari on iPhone, Chrome on Android), open:
   ```
   http://192.168.1.14:3001
   ```
3. **Install as App**:
   - **iPhone (Safari)**: Tap the **Share** button -> Tap **"Add to Home Screen"** 📲
   - **Android (Chrome)**: Tap the **Three Dots Menu** -> Tap **"Install App"** or **"Add to Home screen"** 📲
4. AURA AI will now appear as an icon on your home screen and run in full-screen native mobile mode!

---

## 🚀 Running Locally on Computer

```bash
cd aura-ai-app
npm install
npm run dev

```
